### Tech debt(track 不算里程碑)

#### B1 落地说明

实际审计后(`scripts/audit_schema_consumption.py`),原以为「1/3 字段不消费」
偏乐观——235 个 leaf field 中仅 1 个 (`dataset.caption.strategy`) 是
真正的 backend dead 字段。其余看上去未消费的字段实际由 jobs_helpers
(live preview)、bootstrap (sd-scripts path)、settings (python executable)
等非 compiler 模块消费。

完成动作:
- schema.py 顶部加 module docstring 说明三层消费结构 (compiler /
  runtime / UI-only),避免后续读者再次误判
- `dataset.caption.strategy` 加注释说明它是 UI-only,backends 实际不读
- `scripts/audit_schema_consumption.py` 沉淀为 pre-release 工具,下次
  schema 大改后可直接跑

不动作:
- 19 个 warn-only 字段保留——这是设计意图,让 kohya 配置在 dp 下也能
  validate + 部分编译
- schema 行数没变化(B1 的「瘦身」期望偏)

- `OptimizationConfig.blocks_to_swap` vs `DiffusionPipeOptions.blocks_to_swap` 双源,优先级隐晦
- StubInference 静默回退,前端不知道在画占位图。需要 emit `preview_unavailable` 事件
- 两个 compiler 的 `sampling.attention != "default"` 仅 warn 不实施,schema 字段处于"承诺但不兑现"状态
